## Pick, copy, ship

Search the complete badge reference by service or category. Every entry includes a preview plus ready-to-copy HTML and Markdown for SVG and PNG variants.

## Four styles

Choose between **cozy** and **compact** badges, then use a **minimal** variant when you only need the icon.
